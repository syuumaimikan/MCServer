## 1. 必要な動作環境
- **OS**: Windows 10 / 11, macOS, Linux
- **Java**: 
  - Minecraft 1.20.5〜1.21.x: **Java 21** 推奨
  - Minecraft 1.18〜1.20.4: **Java 17** 推奨
  - ※CraftOSはシステム内のJavaコマンドを自動検出します。
- **メモリ（RAM）**: 8GB以上のPC推奨（サーバーへの割り当ては4GB〜8GB）

---

## 2. ステップ 1: サーバーの新規作成
1. CraftOSのサイドバー上部にある **「＋ 新規サーバー作成」** ボタンをクリックします。
2. 以下の項目を設定します：
   - **サーバー名**: 任意の名前（例: `My Survival SMP`）
   - **サーバータイプ**:
     - ⚡ **Fabric**（推奨）: 最新バージョン対応、Mod導入、超高速な軽量化Mod（Sodium/Lithium）が使える環境
     - 📜 **Paper / Purpur**: プラグイン対応、大人数接続時のTPS負荷軽減に特化
     - 🛠️ **NeoForge / Forge**: 大規模工業・魔術Modパック向け
     - 🪵 **Vanilla**: 公式そのままのバニラ環境
   - **バージョン**: 遊びたいMinecraftバージョンを選択（例: `1.21.1`）
   - **割り当てメモリ**: PCの搭載RAMの半分程度（例: `4GB`〜`8GB`）
   - **EULA自動同意**: チェックを入れたままにします
3. **「作成する」** をクリックすると、公式APIから自動的に最適なJARファイルが高速ダウンロードされ、初期設定が完了します。

---

## 3. ステップ 2: サーバーの起動と状態確認
1. ダッシュボード画面上の緑色の **「起動」** ボタンをクリックします。
2. 画面上部のステータスバッジが `STARTING` から `RUNNING` に変わります。
3. 「コンソール」タブを開くと、サーバーのリアルタイム起動ログを確認できます。
4. ログに `Done (xx.xxs)! For help, type "help"` と表示されれば、サーバーは完全に起動しています。

## 4. ステップ 3: Minecraftから接続する

### 自分自身が接続する場合（サーバーを実行しているPC）:
1. Minecraft Java版を起動します。
2. **「マルチプレイ」** → **「ダイレクト接続」** を選択します。
3. サーバーアドレスに `localhost` と入力して **「サーバーに接続」** をクリックします。

### 同じ家（LAN / Wi-Fi）の家族や友達が接続する場合:
1. CraftOSの「ネットワーク」タブを開きます。
2. **「ローカル接続」** に表示されているIPアドレス（例: `192.168.1.5:25565`）をコピーして友達に教えます。
3. 友達がそのアドレスを入力して接続します。

### 別の家に住む友達が接続する場合（インターネット経由）:
- 外部の友達を招待する方法は [NETWORKING_GUIDE.md](./NETWORKING_GUIDE.md) をご覧ください。（Playit.ggを使うとルーター設定不要で1分で招待できます）

## 5. ステップ 4: 管理者（OP）権限の付与
クリエイティブモードへの変更やコマンドを実行できるように、自分にOP権限を付与します：

- **方法 1（GUIから）**:
  「プレイヤー管理」タブを開き、接続中のプレイヤー一覧から自分の名前の右側にある **「OP付与」** ボタンをクリックします。
- **方法 2（コンソールから）**:
  「コンソール」タブのコマンド入力欄に `op あなたのプレイヤー名` と入力して送信します。

# 🌐 CraftOS ポート開放・マルチプレイ公開マニュアル

自宅のPCで起動しているMinecraftサーバーに、離れた場所に住む友達を招待して一緒に遊ぶための設定手順を徹底解説します。

---

## 📋 3つの公開方法の比較

| 方法 | 手軽さ | ルーター設定 | セキュリティ | 速度・遅延 |
| :--- | :--- | :--- | :--- | :--- |
| ⚡ **UPnP 自動開放 (CraftOS新機能)** | ★★★★★ (ボタン1押し) | **自動** | 自宅IPを公開 | 最速・極低遅延 |
| 🌟 **Playit.gg (推奨)** | ★★★★★ (1分で完了) | **不要** | 高 (IP非公開) | 非常に良好 |
| ⚙️ **手動ルーター設定** | ★★☆☆☆ (知識が必要) | **手動** | 自宅IPを公開 | 最速・極低遅延 |

---

## ⚡ 方法 1: UPnP による全自動ポート開放（最もおすすめ）

CraftOSは、ルーターと自動通信する **UPnP (Universal Plug and Play) IGD クライアント** を内蔵しています。ルーターの設定画面を開くことなく、ボタン1つでポート開放が完了します。

### 手順：
1. CraftOSの **「🌐 ネットワーク」** 画面を開きます。
2. **「⚡ UPnP 全自動ルーターポート開放」** の「UPnP で今すぐポート開放」ボタンをクリックします。
3. ルーターと通信し、数秒で `ポート開放中 (ACTIVE)` に切り替われば成功です！
4. 「パブリックアドレス」（例: `123.45.67.89:25565`）を友達に共有して遊べます。

---

## 🌟 方法 2: Playit.gg を使う（UPnPが通らない環境・ルーター設定不要）

ルーターの管理画面パスワードが分からない場合や、マンション共用インターネット（V6プラス / 二重ルーター等）でポート開放ができない環境でも、**誰でも1分でサーバーを外部公開できます。**

### 手順：
1. **Playit.gg 公式サイトへアクセス**:
   - [https://playit.gg/download](https://playit.gg/download) から Windows / Mac / Linux 用の小さなプログラムをダウンロードします。
2. **プログラムを起動**:
   - ダウンロードしたファイルを実行すると、ブラウザが自動的に開きアカウント連携画面が表示されます。
3. **トンネルを作成**:
   - 「Add Tunnel」ボタンをクリックし、**「Minecraft Java Edition」** を選択します。
   - Local Port に CraftOSで設定したポート（標準は `25565`）を指定します。
4. **アドレスを友達に共有**:
   - 画面に `xxxx.playit.gg` のような専用アドレスが表示されます。
   - CraftOSの「ネットワーク」画面で **「友達用の招待テキストをコピー」** を押し、上記アドレスを貼り付けてDiscordやLINEで友達に送るだけで完了です！

---

## ⚙️ 方法 2: ルーターのポート開放（直接通信・最高速）

自宅のWi-Fiルーターの設定を変更し、外部からのMinecraft接続を直接あなたのPCへ転送します。

### 手順：
1. **PCのローカルIPを確認**:
   - CraftOSの「ネットワーク」タブを開き、「ローカル接続」に表示されているIP（例: `192.168.1.15`）を確認します。
2. **ルーターの設定画面にログイン**:
   - ブラウザで `http://192.168.1.1` または `http://192.168.0.1` を開きます。
   - ルーター本体のシールに記載されているユーザー名・パスワードでログインします。
3. **ポート転送設定を追加**:
   - 「ポート転送」「ポートマッピング」「バーチャルサーバー」などの項目を開きます。
   - 以下の内容で新規ルールを作成します：
     - **プロトコル**: `TCP`
     - **ポート番号**: `25565`
     - **宛先IPアドレス**: 先ほど確認したPCのローカルIP（例: `192.168.1.15`）
4. **Windows Defender ファイアウォールの許可**:
   - Windowsのファイアウォールで `java.exe` の受信通信（TCP 25565）が許可されていることを確認します。
5. **友達にアドレスを共有**:
   - CraftOSの「ネットワーク」タブに表示されている **「パブリックアドレス」**（例: `123.45.67.89:25565`）を友達に伝えます。
